## Create: Dragons Plus 1.9.0

Update compat for ~~That Amazing Mod~~Create Simulated Series (Require Sable at least 1.0.6)

### Update
* Bulk Processing Air Current on Simulated Contraption now interact with block
```
Bulk freezing can freeze water. 
Bulk Blasting can wipe snow, melten ice, lit block and spread fire ("spread fire" is default off on config). 
Bulk Coloring can color block (generated from supported coloring recipes).
Bulk Splashing can extinguish fire and solidate concrete powder.
Interactions of other Bulk Processings are default off in config since there is no interaction pre-set for them.

For modpacker: Interaction is customizable via DataMaps except bulk coloring. Every interaction can be turned on/off in config.
```
